# Privacy Statement

## Local-First Architecture
Hard operates **100% locally on your PC**.
- **No Remote Servers**: Your file paths, installed application lists, disk usage stats, and system performance metrics never leave your computer.
- **Zero Telemetry by Default**: Hard contains no default tracking beacons, Google Analytics, or third-party advertising SDKs.
- **No Cloud Dependencies**: Core cleaning, startup inspection, maintenance tasks, and live monitoring execute without internet access.
- **Opt-In Anonymous Crash Reports**: If an optional crash report toggle is enabled by the user in Settings, only sanitized crash stack traces (free of personal paths or usernames) are submitted with explicit consent.
